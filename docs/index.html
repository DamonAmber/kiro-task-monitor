状态一目了然

每个会话一行，颜色即状态

运行中 · agent 正在执行，显示已运行时长
已完成 · 一轮正常结束，轮到你了
出错 · 报错停下，需要重试
疑似卡住 · 长时间无写入，兜底提醒
等待你确认 · agent 停下等你输入
空闲 / 已取消 · 无进行中的任务

怎么做到的

不依赖任何 Kiro 内部接口

工具只读本地的 Kiro 会话记录（~/.kiro/sessions）：从 session.json 拿标题、工作区与状态，从 messages.jsonl 的事件流（turn_end.stopReason、 pending_interaction）推导每个会话是运行中、已完成，还是出错需要重试。

一键重试：把对应工作区的 Kiro 窗口切到前台，按 ⌘L 聚焦聊天输入框， 自动粘贴「继续」并回车——省去你手动找窗口、敲字。

⚠️ 一键重试依赖 macOS 的辅助功能与自动化（控制 Kiro）权限。 首次点「重试」时系统会弹窗，允许一次即可；仅「监控 + 通知」不需要任何额外权限。
