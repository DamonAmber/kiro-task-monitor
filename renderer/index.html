系统授权自检
一键重试 / 聚焦窗口依赖「辅助功能」权限：系统设置 › 隐私与安全性 › 辅助功能，勾选本应用。仅查看监控状态无需授权。
诊断报告
识别不到会话 / 状态不对时，点「生成报告」导出一个 JSON 发给我们定位。默认已脱敏（不含真实项目名、标题、路径）；需要精确定位再勾选上面的选项。
访问 PIN —
手机连的是哪个网络，就用对应那行的网址（一般是 Wi-Fi）。用 Safari 打开、输入 PIN 即可查看；分享菜单里「添加到主屏幕」后可全屏、横竖屏自适应。首次开启若弹出「允许接受传入网络连接」请点允许。
